Step-by-Step Guide for Every Question

Use these hints to understand what to do. Each question is worth 2 marks.

01

Module I — Sound

ASR pipeline · Argmax · HMM and Viterbi

Task A — Draw an ASR pipeline (0.5 mark)

Draw six labeled boxes in order. Below the diagram, explain the purpose of the HMM (models possible hidden state sequences and observations) and Viterbi (finds the most likely state path in the model).

Speech → Digital Audio → Feature Extraction → HMM → Viterbi → Recognized Text

Task B — Calculate Argmax (0.5 mark)

Make a small table of the candidate words and probabilities. Maximum is the largest probability value; Argmax identifies the word associated with that value.

Practice with different values: If word X has 0.2 and word Y has 0.8, maximum = 0.8 and argmax = Y. Use the probabilities in your assignment for your submission.

Task C — Calculate Viterbi path scores (1 mark)

For each path, multiply Previous Score × Transition Probability × Emission Probability. Write each multiplication separately, then compare the two results. The assumption that both paths reach the same state at the same time step matters.

Check your work: Both results must lie between 0 and 1. Explain why the larger score is retained.
02

Module II — Words and Word Forms

Morphology · Inflection and derivation · Finite-state morphology

Task A — Break words into meaningful parts (0.5 mark)

Use a table with columns Word | Root/Base | Prefix | Suffix. Remember that a word can contain more than one affix.

Different example: unhelpful → prefix un-, base help, suffix -ful.

Task B — Distinguish inflection and derivation (0.5 mark)

Inflection changes grammatical form (for example, tense or number) without creating a new lexical category. Derivation creates a new word, often with a changed meaning or category. Classify each example and explain why.

Task C — Design a finite-state machine (1 mark)

Show a start state, transitions and accepting states for the requested word forms. You can use a shared path for the base word and branches for endings.

START → p → l → a → y → ACCEPT
                         ├→ s → ACCEPT
                         ├→ e → d → ACCEPT
                         └→ i → n → g → ACCEPT
Diagram note: This is only a simple character-recognition sketch. In your report, draw and label the actual states and transitions clearly, and distinguish analysis (word → morphemes) from generation (morphemes → word).
03

Module III — Structures

Context-free grammar · Parse trees · Ambiguity · Probabilistic parsing

Task A — Draw a constituency parse tree (1 mark)

Start from S, expand to NP and VP, and continue applying the grammar rules until each leaf matches a word in the sentence. Label the subject NP and VP.

         S
       /   \
      NP    VP
    /  \   /  \
   Det  N V    NP

This is a partial tree only. Complete all branches and word leaves for the assigned sentence.

Task B — Explain attachment ambiguity (0.5 mark)

Identify the ambiguous phrase, explain two possible meanings, and state what the phrase modifies in each interpretation (the action or a noun phrase).

Task C — Choose a probable parse (0.5 mark)

Compare candidate scores and apply Argmax. Then explain how probabilities can distinguish grammatical structures when the grammar allows more than one.

Study resource: Review your Module 3 lesson for parsing examples and ambiguity.
04

Module IV — Meaning

Word sense · Semantic roles · WordNet · Coreference

Task A — Word sense disambiguation (0.5 mark)

Explain how the surrounding words help distinguish different meanings of the same word.

Different example: mouse can refer to an animal or a computer device; context helps choose the intended sense.

Task B — Label semantic roles (0.5 mark)

Identify the Agent (who acts), Patient (what is affected) and Instrument (what is used) in the assigned sentence.

Task C — WordNet and coreference (1 mark)

Define a synset (a group of word senses expressing one concept), give examples of synonym and hypernym relations, then identify which earlier nouns pronouns refer to.

Example: In “Omar found a phone. He charged it,” He refers to Omar and it refers to the phone.
05

Module V — Web 2.0 Applications

Sentiment · Text entailment · Multilingual question answering

Task A — Aspect-based sentiment (0.5 mark)

Identify the sentiment for each product feature separately, then explain why one overall positive/negative label can hide mixed opinions.

Task B — Text entailment (0.5 mark)

Compare each hypothesis with the premise: Entailment (must be true), Contradiction (cannot both be true under the given assumptions), or Neutral (not determined). Justify each choice.

Task C — Design a multilingual university assistant (1 mark)

Draw a flowchart with the five required stages. Explain how a question written in Arabic can retrieve information from English documents and return a supported answer in Arabic.

Arabic Question → CLIR → English Documents
                 → Question Answering → Arabic Answer
Design tip: Your answer should cite or identify the retrieved university document supporting the response. The assignment asks for a simplified design, not a working application.

Question 1 — Module I: Sound | 2 Marks | CLO1

A. Speech Recognition Pipeline (0.5)

Draw: Speech input → Digital audio → Feature extraction → HMM → Viterbi Algorithm → Recognized text. Briefly explain the roles of HMM and Viterbi.

B. Argmax Calculation (0.5)

Given Cat = 0.15, Car = 0.70, Card = 0.15, find the maximum probability and the Argmax result. Explain the difference.

C. HMM / Viterbi Calculation (1)

Path A: previous score 0.80, transition 0.70, emission 0.90. Path B: previous score 0.60, transition 0.50, emission 0.90. Calculate each new score using Previous Score × Transition × Emission. Assuming both paths reach the same hidden state at the same time step, identify which path Viterbi retains and explain why.

Question 2 — Module II: Words and Word Forms | 2 Marks | CLO2

A. Morphological Analysis (0.5)

For Unhappiness, Replaying, Played, and Teacher, identify root, prefix (if any), and suffix (if any). Explain how this helps NLP.

B. Inflection and Derivation (0.5)

Define both terms and give two examples of each. Classify: Play → Played; Teach → Teacher; Book → Books; Happy → Happiness.

C. Finite-State Morphology (1)

Design an FSM recognizing Play, Plays, Played, and Playing. Show states and transitions; label start and accepting states; explain recognition; give one morphological analysis and one generation example.

Question 3 — Module III: Structures | 2 Marks | CLO2 & CLO3

A. CFG and Parsing (1)

For “The student reads a book”, use S → NP VP; NP → Det N; VP → V NP; Det → the | a; N → student | book; V → reads. Draw a constituency parse tree, identify subject NP and VP, and explain how top-down parsing begins.

B. Attachment Ambiguity (0.5)

For “I saw the man with a telescope”, explain two interpretations and identify what “with a telescope” attaches to in each.

C. Probabilistic Parsing (0.5)

Candidate A = 0.35 and Candidate B = 0.65. Apply Argmax and explain why probabilistic parsing is useful when multiple grammatical interpretations exist.

Question 4 — Module IV: Meaning | 2 Marks | CLO3 & CLO4

A. Word Sense Disambiguation (0.5)

Explain “bank” in (1) “She deposited money at the bank” and (2) “They sat beside the river bank”. How does context help?

B. Semantic Roles (0.5)

For “Sara opened the door with a key”, identify Agent, Patient, and Instrument. Explain why semantic roles matter.

C. WordNet and Coreference (1)

Define synset; give one hypernym and one synonym example. For “Maya bought a laptop. She uses it every day”, identify the referents of “She” and “it”, and explain the value of coreference resolution.

Question 5 — Module V: Web 2.0 Applications | 2 Marks | CLO5

A. Sentiment Analysis (0.5)

For “The screen is excellent, but the battery is terrible”, identify the sentiment for each aspect. Explain why a single overall label can lose information.

B. Text Entailment (0.5)

Premise: “Sara bought a red car.” Classify as entailment, contradiction, or neutral, with reasons: (1) “Sara bought a car.” (2) “Sara bought a blue car.” (3) “Sara drives to university every day.” Assume the same purchase and car.

C. Multilingual NLP Application (1)

Design a university assistant that answers an Arabic question using English university documents. Draw and explain: Arabic question → CLIR → retrieve English documents → question answering → supported answer in Arabic (multilingual generation or machine translation).
