Section B — Six Written Questions

Question 1. Define the following terms:

a. Word Boundary Detection

b. Argmax

c. Hidden Markov Model (HMM)

d. Viterbi Algorithm

e. Automatic Speech Recognition (ASR)

Show Answer

Word Boundary Detection: Identifying where words begin and end in text or speech.

Argmax: An operation that identifies the option associated with the highest value.

HMM: A probabilistic model that represents sequential data using hidden states and observations.

Viterbi Algorithm: An algorithm used to find the most likely sequence of hidden states.

ASR: A system that converts spoken language into written text.

Question 2. Explain the difference between emission probability and transition probability in an HMM. Provide one example of each from speech recognition.

Show Answer

An emission probability describes how likely an observed audio feature is for a particular hidden speech state.

For example, P(O₁ | S₁) = 0.80 means the observation O₁ has probability 0.80 given state S₁.

A transition probability describes how likely the model is to move from one hidden state to another.

For example, P(S₂ | S₁) = 0.70 means the probability of moving from S₁ to S₂ is 0.70.

The HMM uses both probabilities to evaluate possible hidden-state sequences.

Question 3. An ASR system predicts three possible words with the following probabilities:

cat — 0.15

car — 0.70

card — 0.15

Tasks:

a. Identify the maximum probability.

b. Apply Argmax to select the predicted word.

c. Explain why the system selects that word.

Show Answer

a. Maximum probability = 0.70.

b. Argmax = car.

c. The system selects car because it has the highest probability among the three candidate words.

Question 4. Consider two possible HMM paths for recognizing a speech sequence.

Path A: Previous Score 0.80; Transition Probability 0.70; Emission Probability 0.90

Path B: Previous Score 0.60; Transition Probability 0.50; Emission Probability 0.90

Tasks:

a. Calculate the updated score for each path using: Previous score × transition probability × emission probability.

b. Compare the two results.

c. Identify which path should be retained at this step if both paths reach the same state.

Show Answer

Path A: 0.80 × 0.70 × 0.90 = 0.504.

Path B: 0.60 × 0.50 × 0.90 = 0.270.

Since 0.504 > 0.270, Path A has the higher score and should be retained as the best candidate for that state at this step.

Question 5. A speech recognition system recognizes the sentence:

Actual speech: "I lost my credit card."

Recognized text: "I lost my credit car."

Tasks:

a. Evaluate why the recognition may have failed.

b. Explain how sequential context could help distinguish car from card.

c. Recommend two improvements that could make the recognition more reliable.

Show Answer

a. The system may have confused similar acoustic patterns or failed to use enough contextual information.

b. The phrase "credit card" is more likely in this context than "credit car". Context can therefore help the system select the appropriate word.

c. Two possible improvements are better acoustic modeling using more representative training data and stronger use of contextual or language-model information during recognition.

Question 6. Design a simplified Automatic Speech Recognition (ASR) system that converts human speech into written text.

Your design must include:

a. Microphone and audio recording

b. Digital audio conversion

c. Feature extraction

d. HMM with hidden states and observations

e. Viterbi Algorithm

f. Recognized text output

Tasks:

1. Draw a complete block diagram showing the correct order of the components.

2. Explain the function of each component.

3. Demonstrate your system using the spoken sentence "I want ice cream."

4. Explain where the HMM, Viterbi Algorithm, and Argmax operation are used.

Show Answer

A suitable simplified classical ASR design is:

Human Speech ("I want ice cream.") → Microphone → Digital Audio → Feature Extraction → Observations → HMM (hidden states and probabilities) → Viterbi (most likely state sequence) → Recognized Text ("I want ice cream.").

The microphone captures speech, digital conversion produces numerical audio samples, and feature extraction converts the audio into observations. The trained HMM provides hidden-state probabilities, while Viterbi searches for the most likely sequence. Argmax is the mathematical operation for choosing the highest-scoring option and can be used within decoding decisions. The final system produces recognized text.
